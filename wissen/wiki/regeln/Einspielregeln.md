# Einspielregeln

1. Tests grün ([[Testregeln]]).
2. **Prüfung durch Codex vor dem Einspielen:** `/codex:adversarial-review` (wie im Memecoin-Projekt). Befunde bewerten, berechtigte beheben, Tests erneut laufen lassen. Siehe [[Codex-Review]].

4. Bei Änderungen am Workflow: ersten Lauf auf GitHub abwarten und prüfen (grün, Dateien angekommen, Größe).
